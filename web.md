# C# & OONV Interactive Course

Interactive learning platform and exam trainer for C#, OOP, and 16 GoF design patterns with local .NET SDK (Roslyn) compilation.

## Key Features
- **Live C# Compilation:** Compiles and runs user code locally via .NET SDK (Roslyn) with an offline simulator fallback.
- **OOP & GoF Patterns:** Covers C# fundamentals, object-oriented design, and 16 Gang of Four design patterns.
- **Cross-Platform Launcher:** Single Node.js setup (`start.js`) supporting Windows, Linux, and macOS.
- **Desktop Integration:** Includes a Linux `.desktop` installer and frameless web-app launcher (`launch-app.sh`).

## Tech Stack
- **Runtime:** Node.js, .NET SDK (Roslyn)
- **Scripting:** JavaScript, Bash, PowerShell
